# MyAI Pet — Same Style Project

A front-end recreation inspired by the provided MyAI Pet dashboard reference.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. No server or installation is required.

## Included
- Futuristic neon dashboard
- Sidebar navigation
- Riya AI pet dashboard
- Hunger, energy, happiness, cleanliness and friendship
- Feed / Play / Sleep / Pet / Gift interactions
- XP and level system
- Chat interface
- Browser speech recognition button when supported
- Memory, inventory, care, evolution and settings pages
- Responsive design for desktop/tablet/mobile

This is a front-end demo. The AI responses are local demo responses; a real LLM API/backend can be connected later.
